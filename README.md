# PYN v5 — Chibi Wardrobe Update

This version keeps the familiar Roblox-inspired PYN home layout while preserving the fixes from the PYN review document.

## Avatar changes
- Male / Female chibi avatar option
- Multiple eye styles and eye colours
- Skin tone range
- Multiple hair styles and colours
- 24 clothing sets
- Hats and glasses
- A larger accessories collection including bows, cat ears, star clips, scarves, necklaces, backpacks, plushies, headphones, masks, wings, halos, badges, cameras, bags, ties, watches, bracelets and bunny ears
- Some items are free; more unlock by passing lesson exams and project checks

## Home changes
- Keeps the earlier PYN visual style instead of redesigning the whole app
- Friends / active learners are positioned at the top
- No fake people are shown
- Projects remain the main Roblox-like experience cards
- Continue Learning opens the actual lesson
- Video learning row remains available

## Run locally
From this folder:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.
